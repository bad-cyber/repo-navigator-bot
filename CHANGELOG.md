# Changelog

Все заметные изменения в проекте **Repo Navigator Bot** документируются в этом файле.

## - 2026-11-24

### Added
- **Поддержка веток GitHub (`/tree/<branch>`):** парсер URL и загрузчик архивов теперь поддерживают индексацию произвольных веток репозитория с сохранением активной ветки в FSM.
- **Команда `/tree`:** быстрый просмотр отсортированной структуры проиндексированных файлов репозитория.
- **Команда `/audit` (AppSec Audit):** гибридный анализ безопасности, объединяющий статический сканер уязвимостей/утечек (`eval`/`exec`, `pickle.loads`, `yaml.load`, `os.system`, `shell=True`, потенциальный XSS/SQLi, `verify=False`, API-ключи) и LLM-отчёт по найденным рискам.
- **Маскирование секретов (`redact_secrets`):** автоматическая фильтрация случайно попавших в код или ответы LLM токенов и префиксов ключей.
- **Кликабельные ссылки в Telegram HTML:** ссылки вида `file.py:10-25` в ответах бота автоматически преобразуются в прямые ссылки на строки выбранной ветки GitHub (`#L10-L25`).

### Changed
- Обновлена сигнатура `parse_github_url` -> `(owner, repo, branch)` и `download_and_extract_repo` -> `(files, resolved_branch)`.
- Расширен набор модульных тестов (`pytest`) и актуализирована документация `README.md`.

## - 2026-11-23

### Added
- Базовый Codebase RAG пайплайн: скачивание ZIP в RAM, AST-чанкинг через `tree-sitter`, индексация в Qdrant с TTL 2 часа, поиск `multilingual-e5-small` + реранкинг `CrossEncoder`, fallback-цепочка бесплатных моделей OpenRouter.
